# qualR: An R package to download Sao Paulo and Rio de Janeiro air pollution data

A package to download information from CETESB QUALAR
<https://cetesb.sp.gov.br/ar/qualar/> and MonitorAr
[http://jeap.rio.rj.gov.br/je-metinfosmac/institucional/index.html](http://jeap.rio.rj.gov.br/je-metinfosmac/institucional/index.md)
systems. It contains function to download different parameters, a set of
criteria pollutants and the most frequent meteorological parameters used
in air quality data analysis and air quality model evaluation.
